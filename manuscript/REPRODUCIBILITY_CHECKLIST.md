# Reproducibility Checklist

- [ ] Git commit and clean/dirty state recorded.
- [ ] Resolved configuration and random seeds recorded.
- [ ] Hardware, driver, CUDA runtime, and timing recorded.
- [ ] Conda explicit lock, `conda list`, and `pip freeze` saved.
- [ ] Upstream commits, licenses, and asset hashes verified.
- [ ] Data funnel includes ambiguous and failed records.
- [ ] Test split leakage gate passed.
- [ ] Genuine and mock results are visibly distinct.
- [ ] Failed runs remain in the audit.
- [ ] Statistical unit and multiplicity correction declared.
- [ ] Manuscript values trace to successful run manifests.
