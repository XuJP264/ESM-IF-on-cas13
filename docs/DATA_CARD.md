# Data Card

Status: **not yet populated with the real Atlas dataset**.

The planned dataset contains official CRISPR-Cas Atlas v1.0 operons, Cas
effectors, subtype annotations, CRISPR arrays, and high-confidence
Cas13–direct-repeat pairs plus RCSB experimental Cas13 structures. Raw assets
remain local and retain upstream licenses.

The processing funnel separately records all operons, Type VI operons, Cas13
records, exact-unique sequences, high-confidence pairs, ambiguous pairs, and
failures. A record is not assumed to be an independent sequence. Type VI is not
assumed to contain one effector or one array. Direct-repeat orientation is
explicit, and spacers are not treated as verified natural target RNAs.

Real counts, hashes, exclusions, subtype coverage, taxonomic biases, and
missingness will be inserted only after the official source completes.
