# Claims and Evidence

| Level | Permitted claim | Minimum evidence | Forbidden shortcut |
|---|---|---|---|
| 0 | Code and I/O behave as specified | tests, hashes, provenance | file existence alone |
| 1 | Candidate is statistically novel | Atlas-wide search and cluster analysis | parent identity only |
| 2 | Candidate is model-compatible with a backbone | genuine inverse-folding score/sample | mock backend |
| 3 | Candidate is computationally plausible | multiple models and structure prediction | one model score |
| 4 | Cas13 is experimentally effective | wet-lab validation | any computational-only result |

Reports carry `is_mock`, evidence level, model/checkpoint hash, and test status.
Mock outputs never support a scientific claim. Approximate contact or alignment
proxies retain their exact name and are not relabeled as formal scores.
