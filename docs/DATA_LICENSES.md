# Data and Asset Licenses

The MIT license covers project-authored software only. RCSB structures, Atlas
records, model weights, papers, and third-party repositories retain their
upstream terms. Before use or redistribution, consult:

- `data/manifests/` for dataset sources, terms, and hashes;
- `references/manifest.yaml` for paper access status and licenses;
- `third_party/manifest.yaml` and `third_party/LICENSES/`;
- `models/manifest.yaml` for checkpoint terms.

Unknown or unverified terms block redistribution. They do not default to MIT.
